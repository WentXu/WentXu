## 💡 Learned the Hard Way

> **A stronger model does not fix a broken system.**
> Model capability sets the ceiling; systems engineering sets the floor — and production incidents live at the floor.

> **Debug in order: context, then execution, then the model.**
> When an agent gets something wrong, the model's judgment is the *rarest* of the three causes.

> **The eval set is the product.**
> Without a held-out set, every prompt change is blindfolded tuning that feels like progress.

> **Least privilege beats a clever prompt.**
> Prompts shift probabilities; permissions bound the worst case. Only one of those holds when the model is wrong.
